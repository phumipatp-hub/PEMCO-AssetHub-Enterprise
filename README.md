# PEMCO AssetHub Enterprise V2

Google Apps Script based IT Asset Management System.

## Technology

- Google Apps Script
- Google Sheets
- HTML / CSS / JavaScript
- GitHub
- clasp

## Core Modules

- Dashboard
- Asset Management
- Helpdesk
- License Management
- Document Management
- User / Role Management
- Settings
- Audit Logs

## Development Rule

This project uses Google Sheets as database and Google Apps Script as backend.
All configuration must be controlled from Config.gs.
